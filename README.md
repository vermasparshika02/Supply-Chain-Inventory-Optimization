# Supply Chain & Inventory Optimization Analysis

## Project Overview

This project analyzes supply chain performance to identify opportunities for improving inventory management, supplier performance, delivery efficiency, and profitability.

The analysis focuses on key business metrics including revenue, profit, inventory turnover, low-stock risk, supplier delivery performance, and regional sales.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- SQL (SQLite)

## Key Business Questions

1. Which products generate the highest revenue and profit?
2. Which regions perform best?
3. Which suppliers have the fastest delivery performance?
4. Which products are at risk of stockouts?
5. Which products have the highest inventory turnover?
6. Which suppliers have the highest delivery delay rates?
7. Which products generate the highest profit margins?

## Key Metrics

- Total Revenue
- Total Profit
- Units Sold
- Average Inventory
- Inventory Turnover
- Supplier Delivery Time
- Delivery Delay Rate
- Profit Margin

## Dataset

This project uses a simulated business dataset created for portfolio and analytical demonstration purposes.

## Business Impact

The analysis can help businesses:

- Identify low-performing suppliers
- Reduce delivery delays
- Prevent stockouts
- Optimize inventory levels
- Identify high-profit products
- Improve supply chain efficiency
